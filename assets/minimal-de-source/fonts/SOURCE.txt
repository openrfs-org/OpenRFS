The text on this desktop is Misc-Fixed, the bitmap family X has shipped
since R6.  Nothing is vendored here: tools/make-font.py reads the PCF
files off the build machine and writes the glyph tables into src/, so
what the repository carries is the generated header, and this file
records where those bitmaps came from and on what terms.

    face        source file                             package
    6x13        /usr/share/fonts/X11/cyrillic/koi6x13.pcf.gz   xfonts-cyrillic
    7x14        /usr/share/fonts/X11/cyrillic/koi7x14.pcf.gz   xfonts-cyrillic
    9x18        /usr/share/fonts/X11/cyrillic/koi9x18.pcf.gz   xfonts-cyrillic
    mono 8x16   /usr/share/fonts/X11/cyrillic/koi8x16.pcf.gz   xfonts-cyrillic

These are the KOI8-R encodings of the Misc-Fixed faces.  Only ASCII 32
to 126 is read, and in that range the bitmaps are the same ones as the
ISO-8859-1 builds; the Cyrillic halves are the reason these particular
files are the ones Debian still ships.
