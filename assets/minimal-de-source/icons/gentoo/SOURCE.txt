The icons in this folder are Johan Hanson's, drawn in 1998 for the
gentoo file manager.  Nothing here was drawn by this project and nothing
was redrawn: each file is the byte-for-byte original.

They are 16 by 15 and there is no larger version, because in 1998 there
was no larger version: a file manager drew a list and the icon was the
height of a row.  tools/make-icons.py pads the cell to 16 by 16 with a
transparent row and changes nothing else.

TWO THINGS THIS SET DOES NOT HAVE, and neither was invented:

  A trash can.  gentoo has none because a 1998 X file manager deleted
  with unlink and that was that.  The Trash place and the Trash icon on
  the root went with it - they were labels over nothing, since nothing
  here moves a file to a trash or brings it back.

  A terminal.  The launcher that wanted one was on the panel, and the
  panel is gone.
