# OpenRFS panel icon sources

These PNGs are the preserved source inputs for `tools/make-app-icons.py`.
They were imported from the project owner's desktop UI tree at commit
`eb6d32f8bee63025508af992656a7815fa3285c1`, tree
`93319863b82f22b23d8415f04b733cebed6d29f1`.

- `browser.png`, `file-manager.png`, `gnome-fs-desktop.png`,
  `gtk-preferences.png`, `network.png`, `system-file-manager.png`, and
  `terminal.png` come from `lxde-icon-theme` 0.5.1-2.1 (nuoveXT2), licensed
  LGPL-3.0-or-later.
- `volume.png`, `volume-muted.png`, and `wincmd.png` come from `lxpanel-data`
  0.11.1-2, licensed GPL-2.0-or-later. Their upstream filenames were
  `stock_volume.png`, `mute.png`, and `window-manager.png`.

The OpenRFS menu mark is generated separately from
`assets/openrfs/logo.png` by `tools/make-brand-mark.py`.
