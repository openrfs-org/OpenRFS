# OpenRFS identity on the writable ext4plus branch

OpenRFS is the current product, kernel, command-line, desktop, SDK, and release
name. Public references to this development branch must use OpenRFS.

This branch forked before the repository-wide rename. It therefore retains
legacy `phipia` paths, symbols, test markers, fixtures, and historical commits.
Those identifiers are a forward-porting constraint and provenance record, not
the current product identity. They must be reconciled with current `main` before
this branch can merge.

The canonical OpenRFS identity and assets are maintained on `main`. The shell
prompt is `openrfs$`. Public descriptions must state that OpenRFS is experimental
and that privacy is a design goal rather than a certification or anonymity claim.

This branch must not publish a release or use its legacy Phipia-era assets as
current OpenRFS branding.
