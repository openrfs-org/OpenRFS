# RSD identity

RSD stands for **Root Software Distribution**. RSD names the operating system, kernel, command line, installer, desktop, SDK, and releases. Use `rsd` for lowercase code and artifact names and `RSD` for uppercase constants and visible identity. The command prompt is `rsd$`.

The project vision is a complete, inspectable OS foundation that people can fork into their own distributions. Describe implemented behavior precisely and keep limitations beside claims. RSD is experimental software; privacy is a design goal, not a certification.

The current UI source of truth is `ui/`, imported from the RSD interface repository. Its asset notices under `ui/assets/` are part of the distribution. Product documentation should present RSD directly without promotional credits.
